# 视觉实现依据

目标：以飞行社知识页的实际布局、密度和细节为准，替换为 TRAE 品牌和模拟社区内容。美学、观感和还原度优先。

## 2026-09-18 实测

| 元素 | 来源值 | 实现 |
| --- | --- | --- |
| 页面布局 | 外容器 1184px，左右 padding 28px | 内容网格 1128px |
| 主栏 / 间隔 / 侧栏 | 808 / 48 / 272px | 同值 |
| 导航高度 | 60px | 60px |
| 列表首项起点 | x=114px, y=164px（1363×936） | 同值 |
| 封面 | 252×142px，圆角 8px | 同值，4 张生成封面 |
| 标题 | 18px / 28px，500 | 同值 |
| 正文和元信息 | 14px / 20px | 同值 |
| 字体 | PingFang SC, Sarasa Gothic SC, Microsoft YaHei, sans-serif | 同字体优先级 |
| 正文色 / 次级色 | #1f2329 / #646a73 | 同值 |
| 主品牌色 | 飞书蓝 #1456f0 | TRAE 深绿 #008b58；绿色标识 #24e893 |
| 侧栏卡片 | 圆角12px、24px/16px内边距 | 同值 |
| 榜单 | 卡片374px高、条目48px、间隔8px | 同值 |
| 创作者 | 卡片434px高、条目60px、间隔8px | 同值 |
| 移动版（390×844） | 隐藏封面与侧栏；60px顶栏；折叠菜单；横向筛选 | 同结构 |

原站移动端个别超长作者名折成三行，这是内容导致的布局问题，本原型保留作者单行。主体密度和排版不额外做营销页式改造。

## 素材

- `src/icons.json`：从参考页 DOM 采集的实际 SVG 控件图标，保留源路径，非手绘近似。
- `public/assets/trae-mark.png`：原 TRAE 社区公开品牌标识。
- `public/assets/cover-*.png`：本任务生成的演示文章封面，生成图中的机器人为演示插画，不声称是官方授权 IP 素材。
- `public/assets/avatar-*.png`：原社区公开可见头像，用于模拟用户；作者名、文章、互动数均为演示数据，不代表真实用户发表或背书。
