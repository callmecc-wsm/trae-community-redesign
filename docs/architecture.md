# 社区基础结构

页面保持前端原型形态，优先把板块扩展与数据规则分开。当前没有真实后端和用户鉴权。

## 文件职责

- `src/config.js`：导航顺序、展示名称、开关、页面模板、内容类型和输入限制。
- `src/catalog.js`：文章、课程、章节、频道、活动、提示词的模拟数据；ID 是路由与关联的稳定键。
- `src/data.js`：首版文章种子和筛选维度。
- `src/core/model.js`：路由解析／生成、查询、分页、时间状态、课程进度和投稿校验，纯函数可直接测试。
- `src/core/repository.js`：统一读写、数据清洗、v1 数据迁移、跨标签页同步、变更事务和存储失败状态。
- `src/core/hooks.js`：React 订阅适配、导航和 ID 生成。
- `src/components/`：页头、模态框、筛选、文章卡片、按钮与分页等共享组件。组件定义在模块顶层，避免状态更新导致输入框被重新挂载。
- `src/pages/`：各板块页面。文章详情和列表独立，探索页承载课程、频道、活动等页面模板。

## 新增／调整板块

新增一个文章类板块，只需在 `sections` 里配置新的唯一 ID、名称、`template: 'feed'` 和 `types`，补齐内容数据后即可获得导航、独立链接、筛选、排序、分页和详情能力。隐藏时设置 `enabled: false`；已有内容详情仍可通过旧链接打开。

```js
{ id: 'help', label: '帮助与支持', enabled: true, template: 'feed', types: ['问答'] }
```

新增频道时，在 `channels` 中定义稳定 ID，将文章、课程或活动的 `channelId` 指向它。订阅、个人中心与频道内容分类自动复用。完全不同的页面形态需要新增页面模板，不建议伪装成文章列表。

修改主题优先调整 `styles.css` 顶部的 CSS 变量。保留 60px 页头、1128px 内容区、知识页 272px 侧栏和 48px 栏间距。不要随意将知识页改成营销落地页。

## 链接与恢复

使用 hash 路由以支持静态托管。原来的 `#article/1` 继续有效。新路由包括 `#courses`、`#course/first-project`、`#channels`、`#channel/start?tab=discussion`、`#events`、`#profile?tab=bookmarks`。

筛选、排序、分页、搜索、页签和当前章节写入链接，刷新或浏览器返回时恢复。无效路由和找不到的详情显示可恢复的空页，不回落到错误内容。空列表与无搜索结果都有明确反馈。

## 本地数据约束

统一保存到 `trae-community:v2`，首次读取会兼容首版的收藏、点赞、关注、投稿、评论和草稿。不清除原始旧键。形状不正确的字段会被丢弃或归一化，避免解析错误导致白屏。

发布、编辑、删除通过同一个 reducer 完成。删除自己的投稿时，一并清理对应评论、点赞和收藏。评论限制 2000 字，标题 80 字，简介 160 字，正文 20000 字。文本作为 React 文本渲染，不执行用户输入的 HTML。

存储不可用或配额已满时，操作保留在当前内存中，并持续显示“刷新后可能丢失”的提示。多个标签页通过 storage 事件刷新快照；同时写入遵循浏览器本地存储最后写入覆盖规则，不保证跨设备或并发冲突合并。

## 接入后端时的边界

`createRepository` 当前提供同步的本地适配器。真实 API 接入需在该边界新增异步加载／失败／重试状态，并保留页面的查询与领域校验；不能只替换一个 URL 就视为已接通。

服务端需负责认证授权、内容持久化、唯一互动约束、分页查询、内容审核、文件上传、报名容量和错误码。个人中心的本地身份不是权限系统。建议使用接口契约：

| 领域 | 查询                         | 变更                           |
| ---- | ---------------------------- | ------------------------------ |
| 内容 | 列表、详情、按频道和类型查询 | 创建、编辑、删除（校验所有权） |
| 互动 | 当前用户收藏／点赞           | 幂等设置或取消，避免重复计数   |
| 评论 | 按内容分页                   | 创建、删除（校验所有权）       |
| 频道 | 列表、详情                   | 幂等订阅／取消                 |
| 课程 | 课程与章节                   | 按用户记录章节完成状态         |
| 活动 | 状态、议程、容量             | 事务性报名／取消、重复报名约束 |

当前 mock 活动不会向主办方发送信息，提示词不会自动调用任何 AI 服务。运营配置目前通过代码维护，没有宣称已具备 CMS 管理后台。

## 验证

`npm test` 验证领域规则、路由、持久化、损坏数据恢复和托管适配；`npm run build` 验证生产构建；`npm run format:check` 验证源码格式。浏览器验收记录见 `design-qa.md`。本轮没有接入浏览器自动化 CI，交互回归通过实际浏览器操作验证。
