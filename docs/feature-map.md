# 社区板块与交互覆盖

参考站：https://www.feishu.cn/community 。这轮逐一查看了首页、AI 游乐园、课程、知识、模板、频道、活动、频道详情、课程详情和个人中心，以及讨论区和活动历史。保留飞行社的页面结构与视觉语言，内容和品牌改为 TRAE。不是对参考站所有隐藏页面和业务规则的完整逆向。

| 参考板块  | TRAE 对应实现 | 已实现流程                                                     |
| --------- | ------------- | -------------------------------------------------------------- |
| 首页      | 首页          | 精选内容切换、热议换一换、创作者、推荐课程、精选频道、学习入口 |
| AI 游乐园 | AI充电站      | AI 工坊作品、提示词分类、提示词复制、灵感市集、跨板块搜索      |
| 课程      | 课程          | 精选／难度筛选、分页、独立详情、章节、完成／撤销、进度恢复     |
| 知识      | 知识          | 多条件组合筛选、搜索、排序、分页、详情、目录、评论             |
| 模板      | 作品          | 作品列表与详情，复用筛选、收藏、作者与分享能力                 |
| 频道      | 频道          | 目录、订阅／取消、独立详情、概览／讨论／课程／文章／作品／活动 |
| 活动      | 活动          | 当前／过往、按时间判断状态、详情／议程、本地预约／取消、回顾   |
| 个人中心  | 个人中心      | 学习、投稿、收藏、订阅、活动预约、关注、草稿入口               |
| 投稿表单  | 本地编辑器    | 必填／长度校验、草稿、发布、编辑、确认删除及关联数据清理       |

所有课程为图文演示课程。未接入原站视频、直播、积分兑换、证书发放、实际 AI 执行、真实报名、消息通知或用户账号系统。没有在参考站进行投稿、订阅、报名等写操作。

移动端对照使用 390×844 真实 iframe 视口；检查了课程、频道、活动、AI、作品和首页。源站移动页面处于未登录状态，TRAE 为本地体验身份，因此个人欢迎区及账号入口有意不同。课程改为横向图文列表，活动保留左侧时间轴。
