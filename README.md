# TRAE 中文社区

以飞行社为视觉与页面结构参照的 TRAE 社区前端原型。保留知识页的布局、密度和留白，扩展出可独立访问的首页、AI充电站、课程、作品、频道、活动与个人中心。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm ci
npm run dev
```

```bash
npm test
npm run format:check
npm run build
npm run preview
```

生产静态文件输出到 `dist/client/`，可部署到静态托管。项目保留 Sites Worker 适配。GitHub Actions 配置为每次 main 提交或 PR 执行测试、格式检查及构建。

## 可体验的流程

- 知识与作品：多条件筛选、跨板块搜索、排序、分页、文章目录、评论、收藏、点赞、分享。
- 首页：精选内容切换、热门讨论、创作者与频道推荐。
- AI充电站：作品集、提示词分类与复制、灵感内容。
- 课程：精选与难度筛选、课程详情、章节练习、完成／撤销、进度恢复。
- 频道：订阅、独立详情、讨论区及课程／文章／作品／活动分类。
- 活动：当前与过往、独立详情、活动议程、本地预约／取消、回顾。
- 个人中心：最近学习、投稿、收藏、订阅、预约、关注与草稿。
- 投稿：必填及长度校验、自动草稿、发布、编辑、确认删除和关联数据清理。

路由、搜索、筛选、排序、页码、页签与当前章节保存在链接里，支持刷新和浏览器前进后退。首版收藏等数据可以迁移；缓存损坏不会直接导致页面白屏。存储不可用时显示提示，保留当次会话状态。

## 当前边界

这是前端基建与交互原型，尚未接入 Discourse、真实登录、服务端发帖、审核、上传或跨设备同步。演示身份不是权限系统，运营配置通过代码维护，尚无 CMS 后台。

互动、投稿、评论、草稿、学习进度和预约保存在当前浏览器的 localStorage。分享链接可打开内置内容；本地投稿仅对创建它的浏览器有效。多个标签页会同步更新，但同时编辑遵循最后写入覆盖，不保证冲突合并。课程为图文演示，预约不会发送给主办方，提示词不会自动调用 AI。
