# TRAE 中文社区

以飞行社「知识」页为视觉参照的 TRAE 社区前端原型。保留内容列表、筛选和榜单的布局与密度，换成 TRAE 品牌及模拟内容。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm ci
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

静态文件输出到 `dist/client/`，可部署到任意静态托管服务。项目保留了 Sites Worker 的适配文件。

## 已实现

- 桌面双栏知识列表，12 篇模拟文章，4 张定制封面。
- 移动端纯文字列表、折叠导航、横向筛选。
- 场景、产品、板块、专题多选筛选，以及最新排序。
- 搜索建议、结果列表、空状态和清空筛选。
- 文章详情、目录跳转、推荐阅读、评论演示。
- 点赞、收藏、作者资料、关注和分享链接。
- 投稿表单校验及草稿保存。

收藏、点赞、关注、草稿、投稿和评论保存在当前浏览器的 localStorage。分享链接可以打开内置文章；本地投稿仅对当前浏览器有效。

## 当前边界

这是可交互的视觉与产品体验原型，尚未接入 Discourse、真实登录、服务端发帖或审核。导航用同一套列表呈现不同类型的模拟内容；不代表已重构 Discourse 后端。人物名、文章、互动数据与生成封面均用于演示。

## 代码结构

- `src/App.jsx`：页面及交互。
- `src/data.js`：模拟内容、分类和作者数据。
- `src/styles.css`：从参考站实测提炼的设计变量和响应式样式。
- `src/icons.json`：参考页采集的 UI 图标。
- `public/assets/`：本地化图片与品牌素材，不依赖图片外链。
- `docs/design-tokens.md`：设计来源及具体尺寸。
- `design-qa.md`：视觉对照与交互验收记录。
